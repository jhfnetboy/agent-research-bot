# AI 重大技术变化周报 2026-W27

覆盖：2026-06-29 至 2026-07-05（Asia/Bangkok UTC+7）

**本周主线**：Claude Sonnet 5 发布，Fable 5 在与政府协调后恢复上线；AI Engineer World's Fair 期间 Skills、wiki 式记忆和 Agentic MapReduce 成为工程热点；Lilian Weng 把 RSI 重新表述为 harness 工程。本周新闻量偏少。

## 重大变化

### 1. Claude Sonnet 5 发布，Fable 5 恢复上线

- **发生了什么**：06-30 Anthropic 发布 Claude Sonnet 5，1M 上下文，标准价 $3/$15 每百万 token。讨论焦点是效率：新分词器让英文 token 数约增加 1.4 倍（Simon Willison 测算），基准中交互轮次多 3 到 6 倍。07-01 Anthropic 宣布 Fable/Mythos 5 获准重新发布，07-02 按计划上线（二手）。
- **为什么重要**：单价不变而 token 数和轮次增加，再次说明 Agent 成本要按“每完成一个任务”算，而不是看标价。Fable 停服约三周后恢复，供应商风险事件告一段落。
- **来源**：[Anthropic: Claude Sonnet 5](https://www.anthropic.com/news/claude-sonnet-5)（2026-06-30）；[Anthropic on X：Fable 恢复](https://x.com/AnthropicAI/status/2072106151890809341)（2026-07-01）；[AINews](https://latent.space/p/ainews-sonnet-5-today-and-fable-5/)（2026-07-01，二手汇总）

### 2. Devin Security Swarm：用 Agentic MapReduce 找漏洞

- **发生了什么**：07-02 Cognition 发布 Devin Security Swarm，把有边界的 Agent 扇出到整个代码库，汇总发现后再验证可利用性，只上报确认过的漏洞；称一家财富 500 强试点在生产仓库中发现并修复了一千多个漏洞（二手）。
- **为什么重要**：多 Agent 扇出在安全审计这一具体企业流程上落地，“先扇出、再汇总、再验证”的结构后来在 OpenAI 自治修复 Linux 内核漏洞（W45）中再次出现。
- **来源**：[Cognition on X](https://x.com/cognition/status/2072368168182432109)（2026-07-02）；[AINews](https://latent.space/p/ainews-not-much-happened-today-900/)（2026-07-02，二手汇总）

### 3. wiki 式记忆成为 Agent 设计模式，LangChain 推出 OpenWiki

- **发生了什么**：社区提出用 wiki 结构做 Agent 记忆，07-02 LangChain 发布 OpenWiki，用 openwiki --init 为代码库生成并维护供 Agent 读取的文档。记忆系统从“只检索”转向“对账与维护”（二手）。AIEWF 期间 Skills 设计也是大会主线话题。
- **为什么重要**：Agent 在不同线程之间反复丢失上下文，可检查、可维护的知识层比原始日志更有用。这与 RAG 从向量检索走向结构化知识的趋势一致。
- **来源**：[LangChain: OpenWiki](https://x.com/LangChain/status/2072376975545798792)（2026-07-02）；[AINews](https://latent.space/p/ainews-not-much-happened-today-900/)（2026-07-02，二手汇总）；[AINews: Skills 主题](https://latent.space/p/ainews-not-much-happened-today-07e/)（2026-06-30，二手汇总）

### 4. Lilian Weng：Harness Engineering for Self-Improvement

- **发生了什么**：07-04 Lilian Weng 发表长文 Harness Engineering for Self-Improvement，把递归自我改进的讨论从“模型直接改自己的权重”转向“围绕模型的 harness 如何让系统持续变好”，Sakana 将其与 AI Scientist、ShinkaEvolve、Darwin Gödel Machine 联系起来（讨论据 AINews 07-08 转述）。
- **为什么重要**：这篇综述给“harness 即产品”和“RSI”两条线提供了统一框架：自我改进可以先发生在提示、工具、记忆和评测闭环上，而不必等模型改权重。
- **来源**：[Lil'Log](https://lilianweng.github.io/posts/2026-07-04-harness/)（2026-07-04）；[AINews](https://latent.space/p/ainews-lilian-weng-summarizes-35/)（2026-07-08，二手汇总）
