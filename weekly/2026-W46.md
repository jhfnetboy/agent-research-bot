# AI 重大技术变化周报 2026-W46

## 重大变化

### 1. Claude Fable 5.2 / Mythos 5.2

- **发生了什么**：11-09 Anthropic 发布同一底座的 Fable 5.2 与 Mythos 5.2（后者只给审核机构），价格降到每百万 token $8/$40。官方案例：1000 个 Agent 30 小时完成费马大定理的 Lean 形式化，1000 多个子 Agent 8 天写出可启动的操作系统。Anthropic 写明在训练中限制了最直接加速 AI 研发的能力。AA Index v5 以 65 分第一，但 SemiAnalysis GDPx 每任务成本从 $67 升到 $88（二手）。
- **为什么重要**：“强模型做 Orchestrator、小模型做 Worker”成为官方推荐用法；头部实验室第一次公开对 RSI 相关能力做训练期限制。单价降、每任务成本升，成本要按任务算。
- **来源**：[Anthropic](https://www.anthropic.com/news/claude-fable-and-mythos-5-2)（2026-11-09）；[AINews: Fable 5.2](https://latent.space/p/ainews-fable-5-2-retakes-world-1-llm-spot-as-ant-ipo-roadshow-begins/)（2026-11-10，二手汇总）

### 2. Gemini 4 Carbon 全面可用，Antigravity 推出 /swarm

- **发生了什么**：11-10 Gemini 4 Carbon 通过 Gemini API、AI Studio 等全面开放，11-30 前 $2/$10。Antigravity 新增 /swarm：一个提示词拉起多 Agent 团队，在实时留言板上协调，每个角色可用不同模型。
- **为什么重要**：继 Fable 5.2 之后，Google 也把“协调者、执行者、验证者”的多 Agent 结构做进产品。
- **来源**：[DeepMind Blog](https://deepmind.google/blog/gemini-4-carbon-is-now-available/)（2026-11-10）；[AINews](https://latent.space/p/ainews-mercor-750m-series-d-at-20b-valuation-3b-run-rate/)（2026-11-11，二手汇总）

### 3. AlphaProof Code：用 Agent 形式化验证真实软件

- **发生了什么**：11-10 DeepMind 发布 AlphaProof Code，用 Agent 生成超过 600 万行 Lean 证明，验证了 Signal 协议实现代码的关键安全性质。
- **为什么重要**：形式化验证从数学定理扩展到生产代码，与 W43 Anthropic 的 Rocq 工作形成同一趋势：用可机器检查的证明给 Agent 产出兜底。
- **来源**：[DeepMind Blog](https://deepmind.google/blog/introducing-alphaproof-code/)（2026-11-10）

### 4. 紧急停止、权重后门、推理商数据保留

- **发生了什么**：11-09 OpenAI 公开 Control Room，可快速叫停研究基础设施上的模型任务。11-10 Microsoft Research 公布 Lazarus：改不到 10 个休眠神经元即可给 Agent 植入后门，要和原始权重做 diff 才能可靠发现。Notion 披露 AI 供应商 Fireworks AI 违反零数据保留承诺，已断开合作。
- **为什么重要**：风险分别出在运行时、模型供应链和推理供应商三层，Agent 有了工具权限后任何一层出问题都会被放大。
- **来源**：[OpenAI: Control Room](https://openai.com/index/control-room)（2026-11-09）；[Microsoft Research: Lazarus](https://www.microsoft.com/en-us/research/blog/lazare-veni-foras-reprogramming-dormant-neurons-to-backdoor-ai-agents/)（2026-11-10）；[Notion 安全事件说明](https://www.notion.com/help/security-incident-involving-a-third-party-ai-vendor)（2026-11-10，页面无日期，按 HN 讨论日）
