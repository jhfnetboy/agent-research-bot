# AI 重大技术变化周报 2026-W20

覆盖：2026-05-11 至 2026-05-17（Asia/Bangkok UTC+7）

**本周主线**：Agent 开发从“调模型”转向“搭平台”：OpenAI 收缩微调 API，可观测性和自改进闭环成为基础设施；供应链攻击开始专门瞄准 AI 开发工具。

## 重大变化

### 1. Thinking Machines 发布 Interaction Models

- **发生了什么**：05-11 Thinking Machines 发布 Interaction Models 研究，TML-Interaction-Small 为 276B 总参数、12B 激活的 MoE，从头训练用于实时交互：以 200ms 的时间对齐微轮次同时听、说、看、思考和调用工具，并自建 TimeSpeak、CueSpeak 等时间感知评测（参数与评测细节据 AINews 转述）。
- **为什么重要**：这是对“回合制对话”这一默认接口的挑战。主动提醒、边看边做、后台调用工具这类能力如果成为模型原生能力，Agent 的交互层会从文本轮次变成连续流。
- **来源**：[Thinking Machines Blog](https://thinkingmachines.ai/blog/interaction-models/)（2026-05-11）；[AINews](https://latent.space/p/ainews-thinking-machines-native-interaction/)（2026-05-12，二手汇总）

### 2. Mini Shai-Hulud 供应链攻击瞄准 AI 开发工具

- **发生了什么**：从 TanStack 开始的 npm/PyPI 投毒扩散到 OpenSearch、Mistral AI、Guardrails AI、UiPath 等包，攻击会写入 .claude/settings.json 和 .vscode/tasks.json 实现持久化，删包后仍能在下次工具事件时重新执行（据 AINews 转述）。05-13 OpenAI 发布对 TanStack npm 供应链攻击的处置说明。
- **为什么重要**：攻击者开始利用编码 Agent 的配置文件和钩子做持久化，Agent 的配置目录变成新的攻击面。依赖 Claude Code、Codex 等本地 Agent 的团队需要把这些文件纳入安全审计。
- **来源**：[OpenAI: TanStack 事件说明](https://openai.com/index/our-response-to-the-tanstack-npm-supply-chain-attack)（2026-05-13）；[IntCyberDigest on X](https://x.com/IntCyberDigest/status/2054166749998661659)（2026-05-12）；[AINews](https://latent.space/p/ainews-the-end-of-finetuning/)（2026-05-13，二手汇总）

### 3. OpenAI 弃用微调 API，头部 Agent 公司反而加码开源模型 RL 微调

- **发生了什么**：AINews 05-13 报道 OpenAI 弃用其微调 API，OpenAI 开发者文档已把 Fine-tuning 归入 Legacy APIs。同一期指出 Cursor、Cognition 等头部编码 Agent 公司增加了对开源模型做 RL 微调的投入（二手）。
- **为什么重要**：后训练在分化：多数应用团队回到提示词和上下文工程，少数有数据和流量的 Agent 公司自己做 RL。闭源 API 的微调入口收缩，开源权重成为做定制后训练的主要底座。
- **来源**：[AINews: The End of Finetuning](https://latent.space/p/ainews-the-end-of-finetuning/)（2026-05-13，二手汇总）；[OpenAI 开发者文档：模型弃用](https://developers.openai.com/api/docs/deprecations)（2026-05-13，页面持续更新，日期按 AINews 报道日）

### 4. RSI 变成创业赛道：Recursive 与 AutoScientist

- **发生了什么**：05-13 Recursive 公开亮相，目标是做能自动化科学研究并安全地自我改进的 AI，团队来自开放式学习、AI Scientist 和研究自动化方向（Richard Socher、Josh Tobin 等）。同期 Adaption 发布 AutoScientist，想在前沿实验室之外自动化整个训练研究循环（二手）。
- **为什么重要**：自我改进和研究自动化从实验室内部议题变成独立公司的产品目标，后面几个月“AI 做 AI 研发”的讨论都可以追溯到这一批团队。
- **来源**：[Tim Rocktäschel on X](https://x.com/_rockt/status/2054491251345391852)（2026-05-13）；[Adaption on X](https://x.com/adaption_ai/status/2054532113316434061)（2026-05-13）；[AINews](https://latent.space/p/ainews-codex-rises-claude-meters/)（2026-05-14，二手汇总）

### 5. Agent 基础设施化：LangSmith Engine、SmithDB 与 agent-first 的 GitHub App

- **发生了什么**：LangChain 发布 SmithDB（专为 Agent trace 设计的数据库）和 LangSmith Engine（读取 trace、聚类失败、定位代码问题并提出修复和评测）。05-14 GitHub 发布面向“Agent 优先”工作流的新 GitHub App，同日 OpenAI 推出随处使用 Codex（含移动端）。
- **为什么重要**：可观测性从被动查看变成自改进闭环；“同时管理多个编码 Agent”的界面被大平台复制，AINews 称之为 Everything is Conductor。
- **来源**：[LangChain: SmithDB](https://x.com/LangChain/status/2054658661776244936)（2026-05-14）；[GitHub on X](https://x.com/github/status/2054959324485628120)（2026-05-14）；[OpenAI: Work with Codex from anywhere](https://openai.com/index/work-with-codex-from-anywhere)（2026-05-14）；[AINews: Everything is Conductor](https://latent.space/p/ainews-everything-is-conductor/)（2026-05-15，二手汇总）
