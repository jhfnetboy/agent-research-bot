# AI 重大技术变化周报 2026-W28

覆盖：2026-07-06 至 2026-07-12（Asia/Bangkok UTC+7）

**本周主线**：GPT-5.6 三档家族发布，OpenAI 称 Sol 自主完成了 Luna 的后训练；Anthropic 发现模型内部的“全局工作空间”；Grok 4.5、Muse Spark 1.1、Hy3 让前沿梯队更拥挤。

## 重大变化

### 1. GPT-5.6 Sol/Terra/Luna 发布，“Sol 自主后训练了 Luna”

- **发生了什么**：07-09 OpenAI 发布 GPT-5.6 三档模型和多级推理强度，Responses API 加入 Programmatic Tool Calling 和多 Agent beta，Codex 成为新 Work 产品的核心。发布中最具争议的说法是 GPT-5.6 Sol 自主完成了 GPT-5.6 Luna 的后训练，社区对这句话的实际含义很快产生分歧（二手）。
- **为什么重要**：如果按字面理解，这是前沿实验室首次称模型自主完成另一个生产模型的后训练，是 RSI 讨论的关键节点；同时多 Agent 和程序化工具调用进入官方 API，编排成为平台能力。
- **来源**：[OpenAI: GPT-5.6](https://openai.com/index/gpt-5-6)（2026-07-09）；[OpenAIDevs：Programmatic Tool Calling 与 Multi-agent beta](https://x.com/OpenAIDevs/status/2075274093327470923)（2026-07-10）；[AINews](https://latent.space/p/ainews-openai-launches-gpt-56-solterraluna/)（2026-07-10，二手汇总）

### 2. Anthropic：语言模型中的全局工作空间（J-space）

- **发生了什么**：07-06 Anthropic 发布 A global workspace in language models，称在 Claude 内部找到一小组被称为 J-space 的激活，具有类似“全局工作空间”的作用：可被报告、可被调制、支持灵活推理；同时在 Neuronpedia 上提供开源权重模型的演示（二手）。
- **为什么重要**：这类可解释性结果为监控和干预 Agent 的内部状态提供了可能的抓手，也和 Fable 5 用 steering vector 限制能力的做法属于同一工具箱。
- **来源**：[Anthropic Research](https://www.anthropic.com/research/global-workspace)（2026-07-06）；[Anthropic on X](https://x.com/AnthropicAI/status/2074185348142280912)（2026-07-07）；[AINews](https://latent.space/p/ainews-the-field-guide-to-fable/)（2026-07-07，二手汇总）

### 3. OpenAI：编码评测的信号与噪声，SWE-Bench Pro 被认为已饱和

- **发生了什么**：07-08 OpenAI 发布 Separating signal from noise in coding evaluations，讨论编码评测中的噪声来源；据 AINews，OpenAI 评测团队认为 SWE-Bench Pro 已饱和且存在根本缺陷（二手）。
- **为什么重要**：继 FrontierCode 之后，模型厂商自己也承认主流编码基准失效，评测方法论本身成为研究课题。
- **来源**：[OpenAI](https://openai.com/index/separating-signal-from-noise-coding-evaluations)（2026-07-08）；[AINews](https://latent.space/p/ainews-spacexai-launches-grok-45/)（2026-07-09，二手汇总）

### 4. Grok 4.5、Muse Spark 1.1、腾讯 Hy3

- **发生了什么**：07-08 Cursor 博客发布与 SpaceXAI 合作的 Grok 4.5，主打编码和 Agent（AA 估计约 1.5T 参数，二手）。Meta 发布 Muse Spark 1.1 并首次通过 Meta Model API 开放。腾讯以 Apache 2.0 开源 Hy3：295B MoE、21B 激活、256K 上下文，强调工具调用稳定性（二手）。
- **为什么重要**：前沿梯队从三家扩展到五六家，开源侧也持续有可用于 Agent 的大模型，模型选择和路由的重要性上升。
- **来源**：[Cursor: Introducing Grok 4.5](https://cursor.com/blog/grok-4-5)（2026-07-08）；[Meta: Muse Spark 1.1](https://ai.meta.com/blog/introducing-muse-spark-meta-model-api/)（2026-07-09，页面无日期，按 AINews 报道）；[Hy3 on X](https://x.com/eliebakouch/status/2074011171661701466)（2026-07-06）
