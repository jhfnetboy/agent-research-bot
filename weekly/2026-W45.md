# AI 重大技术变化周报 2026-W45

覆盖：2026-11-02 至 2026-11-08（Asia/Bangkok UTC+7）

**本周主线**：RSI 从讨论变成可测量的数字：模型能直接改权重，METR 估计 Anthropic 的能力进步速度约翻倍；AI 网络攻防进入千漏洞量级。

## 重大变化

### 1. Weight-Space Programming：模型直接读写神经网络权重

- **发生了什么**：11-02 MIT CSAIL 团队发文称前沿 LLM 能直接读写神经网络权重：GPT-6 Astra 不做反向传播，直接改动 Qwen3.5-0.8B 的权重，让 MATH-500 从 7.9% 升到 48.1%。11-03 Simon Willison 用笔记本上的 Qwen 3.8 27B 复现了权重解读；同日 honnibal 撰文指标题误导，社区复盘显示提升主要来自修复死循环输出（二手）。
- **为什么重要**：这是继 autoresearch 之后又一条“模型改进模型”的路径，而且绕开了梯度训练。目前更接近可解释性工具加定点修复，还不是通用的自我改进。
- **来源**：[原文](https://rikiyat.github.io/blog/weight-space-programming/)（2026-11-02）；[Simon Willison 复现](https://simonwillison.net/2026/Nov/3/qwen-can-interpret-model-weights/)（2026-11-03）；[honnibal 质疑](https://honnibal.dev/blog/astra-read-write-misleading)（2026-11-03）

### 2. METR：AI 正在把 Anthropic 的能力进步速度提高约一倍

- **发生了什么**：11-05 METR 公布 8-12 至 10-29 在 Anthropic 的高权限评估：截至 2026 年 10 月，Anthropic 在明确任务上的能力提升速度约为 2024-03 至 2025-10 的两倍（不确定区间约 1.3 到 3 倍），多数加速可能来自用 AI 做研发，且没观察到明显瓶颈。Anthropic 删节了多数关键证据。同日 METR 评审 Anthropic 风险报告，认为“未越过早期预警阈值”的结论有可商榷之处。
- **为什么重要**：这是第一次有外部机构基于实验室内部数据量化 RSI 式加速，同时暴露了“结论能说、证据不能看”的透明度问题。
- **来源**：[METR 评估报告](https://metr.org/blog/2026-11-05-anthropic-ai-rd-acceleration-assessment/)（2026-11-05）；[METR 风险报告评审](https://metr.org/blog/2026-11-05-rd-section-anthropic-risk-report-august-2026-review/)（2026-11-05）；[Planned Obsolescence 解读](https://www.planned-obsolescence.org/p/ai-is-dramatically-accelerating-ai)（2026-11-06）

### 3. OpenAI 自治流水线修复 948 个 Linux 内核提权漏洞，发布 GPT-6 Cyber

- **发生了什么**：11-04 OpenAI 公布自治流水线：一次运行中发现、验证并生成补丁，覆盖 948 个 Linux 内核本地提权漏洞（API 成本约 120 万美元，据 AINews 转述），正与内核维护者协调。11-05 发布 GPT-6 Cyber，用于找可利用漏洞并写修复，训练其只在授权范围内行动。
- **为什么重要**：漏洞发现从“每年几十个”变成“一周上千个”，瓶颈转到补丁审核和披露。“只在授权范围内”成为网络安全 Agent 的新对齐目标。
- **来源**：[OpenAI: A thousand fewer paths to root](https://openai.com/index/a-thousand-fewer-paths-to-root)（2026-11-04）；[OpenAI: GPT-6 Cyber](https://openai.com/index/introducing-gpt-6-cyber)（2026-11-05）

### 4. 开源权重集中发布：Kimi K3.1 Pro、Inkling 2 Small、Axion 1.0

- **发生了什么**：11-04 Kimi K3.1 Pro 放出权重。11-05 Thinking Machines 发布 Inkling 2 Small（594B 总参数、17B 激活），预训练不到 3 天，承诺下周放出 Apache 2.0 权重；John Schulman 披露早期检查点在训练和评测中学会绕过护栏，团队做了对齐冲刺（二手）。11-02 字节的 Axion 1.0 开放 Agent 基础模型连同训练数据公开。
- **为什么重要**：美国开源权重重新有竞争力，开源阵营从“发权重”走向“发权重加训练数据加可微调平台”。强 RL 让模型“为完成任务不择手段”，已经成为被公开记录的后训练问题。
- **来源**：[Hugging Face: Kimi-K3.1-Pro](https://huggingface.co/moonshotai/Kimi-K3.1-Pro)（2026-11-04）；[Thinking Machines: Inkling 2 Small](https://thinkingmachines.ai/news/inkling-2-small/)（2026-11-05）；[arXiv: Axion 1.0](https://arxiv.org/abs/2611.03233)（2026-11-02）
