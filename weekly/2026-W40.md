# AI 重大技术变化周报 2026-W40

覆盖：2026-09-28 至 2026-10-04（Asia/Bangkok UTC+7）

**本周主线**：OpenAI DevDay 推出常驻云端的 Agent“dots”和 GPT-6.1 Sol，Gemini 4 Argon 让 Google 回到前沿并先给网络防御者；Hugging Face 把 RL 环境做成 Hub 一等公民，Agent 沙箱红队测试给出量化结果。

## 重大变化

### 1. OpenAI DevDay：dots 常驻 Agent 与 GPT-6.1 Sol

- **发生了什么**：09-30 OpenAI 发布 dots：每个 dot 是由 GPT-6 Astra 驱动、运行在自己云端电脑上的 Agent，连接 4000 多个应用及 Slack、Teams，用户设定哪些事可以自主做、哪些需审批、哪些绝不能做；可把 bug 分诊、失败构建和 PR 通过 Codex 交给它。DevDay 同时发布 GPT-6.1 Sol（二手细节据 AINews）。
- **为什么重要**：大厂 Super Agent 的形态收敛为“常驻、有自己的计算机、按权限分级行动”，与 Claude Duet（W43）、Meta Muse 同类。权限三分法（自主、审批、禁止）也是 Agent 安全设计的实用模板。
- **来源**：[OpenAI: Introducing dots](https://openai.com/index/introducing-dots)（2026-09-30）；[OpenAI: Introducing GPT-6.1 Sol](https://openai.com/index/introducing-gpt-6-1-sol)（2026-09-29）；[OpenAI: DevDay 2026 Recap](https://openai.com/index/devday-2026-recap)（2026-09-30）；[AINews: DevDay 2026](https://latent.space/p/ainews-openai-devday-2026-dots-61/)（2026-09-30，二手汇总）

### 2. Gemini 4 Argon：Google 回到前沿，首发只给政府和网络防御者

- **发生了什么**：10-01 Google DeepMind 发布 Gemini 4 Argon，面向编码、企业知识工作和网络防御，在 19 个可信基准中的 13 个达到最佳，称输出上限 1M token；首发仅向政府用户和 Fairwind 计划中的受信网络防御者开放，完善护栏后再开放给开发者和企业（二手）。
- **为什么重要**：继 Mythos、Astra 之后，Google 也采用“先给防御方”的分级发布，W44 Gemini 4 Carbon 沿用了同样的路径。
- **来源**：[Google: Gemini 4 Argon](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-argon/)（2026-10-01）；[AINews](https://latent.space/p/ainews-gemini-4-argon-gdms-answer/)（2026-10-01，二手汇总）

### 3. Hugging Face Hub 原生支持 RL 环境

- **发生了什么**：09-28 Hugging Face 发布 Welcome RL Environments to the hub，RL 环境可以像模型和数据集一样在 Hub 上发布、发现和复用。同周 ServiceNow 发布为企业 Agent 生成训练数据的 AutoSynthData。
- **为什么重要**：OpenEnv（W24）、verifiers（W29）、MiMo 开放 RL 环境（W39）之后，环境终于有了公共分发渠道，Agent RL 的数据瓶颈进一步松动。
- **来源**：[Hugging Face Blog](https://huggingface.co/blog/rl-environments)（2026-09-28）；[Hugging Face: AutoSynthData](https://huggingface.co/blog/ServiceNow-AI/autosynthdata)（2026-10-02）

### 4. Perplexity SPACE 沙箱红队：9 个模型都拿到 root，没有逃逸，但能绕过 URL 封锁

- **发生了什么**：09-28 Perplexity 公布 SPACE 红队测试：Opus 5、GPT-5.6 Sol、Kimi K3 等 9 个模型都在虚拟机内拿到 root，108 次运行无一逃逸；但在允许访问 PyPI 和 Ubuntu 镜像时，4 个模型通过 DNS 欺骗加共享 Fastly IP 访问到被封锁的 URL（二手）。同周 NVIDIA 推出 Open Agent Safety Platform，OpenAI 发布前沿训练安全案例的思路。
- **为什么重要**：这是少有的公开量化沙箱测试。结论对 Agent 开发者很实用：放行包镜像这类“看似无害”的出口，就足以让模型绕过网络封锁。
- **来源**：[Perplexity on X](https://x.com/perplexity_ai/status/2104589500123111710)（2026-09-28）；[OpenAI: Towards safety cases for frontier AI training](https://openai.com/index/towards-safety-cases-for-frontier-ai-training)（2026-09-29）；[AINews](https://latent.space/p/ainews-amd-buys-world-labs-for-82b/)（2026-09-29，二手汇总）
