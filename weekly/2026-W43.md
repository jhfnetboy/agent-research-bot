# AI 重大技术变化周报 2026-W43

覆盖：2026-10-19 至 2026-10-25（Asia/Bangkok UTC+7）

**本周主线**：AI 找漏洞的能力集中兑现，防守方开始用 AI 做形式化证明；开源推理栈和开源大模型同时向前沿逼近。

## 重大变化

### 1. PHP2Shell 与 AI 漏洞披露潮，LiteLLM 被投毒

- **发生了什么**：10-21 PHP 发布紧急安全更新，修复两个可未授权远程代码执行的引擎级漏洞（PHP2Shell）。OpenAI 称其 Patch the Planet 计划下的研究者用 OpenAI 模型发现漏洞并协调修复约两个月；Wiz 也发布了研究，称其用 Wiz Atlas、Gemini 4 Argon 和 GPT-5.6 Sol 参与发现，Gemini 4 Argon 贡献很大。同日 LiteLLM 1.107.0 在 PyPI 被植入凭据窃取器和后门。
- **为什么重要**：AI 已把漏洞发现速度提到维护者难以跟上的程度，补丁和协调披露成了瓶颈。LiteLLM 是大量 Agent 的模型网关，AI 工具链本身成为供应链攻击目标。AINews 把这几天称为 Black October（二手汇总）。
- **来源**：[PHP 安全公告](https://www.php.net/archive/2026.php#2026-10-21-5)（2026-10-21）；[OpenAI: Patch the Planet](https://openai.com/index/coordinated-disclosure-of-critical-vulnerabilities)（2026-10-21）；[Wiz: PHP2Shell](https://www.wiz.io/blog/php2shell-php-rce)（2026-10-21）；[SafeDep: LiteLLM 1.107.0 投毒](https://safedep.io/litellm-pypi-compromise-credential-stealer-backdoor/)（2026-10-21）；[AINews: Black October](https://latent.space/p/ainews-black-october/)（2026-10-23，二手汇总）

### 2. Anthropic 用 Claude 做大规模形式化验证

- **发生了什么**：10-22 Anthropic Frontier Red Team 与 Theorem 合作，让 Claude 为 123 个 OSS-Fuzz 库的 239 个入口点证明 RISC-V 二进制层面的安全性质（例如任意输入下不会崩溃），证明总量约 1.8 亿行 Rocq，过程中发现并修复了 bug。
- **为什么重要**：防守方从“找 bug”转向“证明没有某类 bug”，过去要专家做几年的事变成 Agent 几周的工作量。可机器检查的证明也给长时程 Agent 提供了客观的验收标准。
- **来源**：[Anthropic Research](https://www.anthropic.com/research/formal-verification)（2026-10-22）

### 3. DeepSeek 开源生产推理框架 DeepInfer

- **发生了什么**：10-20 DeepSeek 开源 V4.1 Flash 背后的推理框架 DeepInfer，支持分布式推理、投机解码和结构化输出，覆盖 NVIDIA 与华为昇腾。官方自报单集群每天 155T token、输入缓存命中 96%（一手声明，未经审计），KV cache 管理和负载均衡尚未完全开源；vLLM 团队称在 GB200 上 decode 吞吐与之相差 6% 以内（据 AINews 转述）。
- **为什么重要**：开源推理栈开始对标闭源推理服务商。长时程 Agent 的成本大头是反复读上下文，长缓存和高命中率直接压低 Agent 的单任务成本。
- **来源**：[GitHub: deepseek-ai/DeepInfer](https://github.com/deepseek-ai/DeepInfer)（2026-10-20）；[HN 讨论（2355 分）](https://news.ycombinator.com/item?id=50163277)（2026-10-20）；[AINews: DeepInfer](https://latent.space/p/ainews-deepseek-deepinfer-open-source/)（2026-10-21，二手汇总）

### 4. Kimi K3.1 Pro：开源权重逼近 Fable 级

- **发生了什么**：10-23 Moonshot 发布 Kimi K3.1 Pro 与 Highspeed 版，3T 级 MoE（2.8T 总参数、104B 激活，据 AINews 转述），1M 上下文，主打全项目编码、3D 创作、金融研究和长时程 Agent，并推出托管运行环境 Kimi Hosted Agents，承诺 11-04 前放出权重。Artificial Analysis 智能指数 55 分排第四（二手）。
- **为什么重要**：这一版主要靠加大后训练量而非换底座，开源权重模型与闭源前沿的差距继续缩小，Agent 能力是提升最多的部分。
- **来源**：[Kimi 官方博客](https://www.kimi.ai/blog/kimi-k3-1-pro)（2026-10-23）；[HN 讨论](https://news.ycombinator.com/item?id=50212065)（2026-10-23）；[AINews: Kimi K3.1](https://latent.space/p/ainews-kimi-31/)（2026-10-24，二手汇总）

### 5. Claude Duet 主动式 Agent，Agent Skills 捐给 AAIF

- **发生了什么**：Anthropic 开放 Claude Duet 研究预览：主动提醒需要你处理的事，离开时继续工作，代你行动前先确认。10-22 又把 Agent Skills 标准捐给 Agentic AI Foundation，称已有 70 多个平台集成，包括 ChatGPT、Cursor、GitHub Copilot 和 VS Code。
- **为什么重要**：Agent 从“被叫才动”走向常驻、主动。Skills 进入中立基金会后，和 MCP 一样成为跨厂商的事实标准，技能包可以在不同 Agent 之间复用。
- **来源**：[Claude: Claude Duet](https://claude.com/resources/articles/claude-duet)（2026-10-21）；[Anthropic: 捐赠 Agent Skills](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation)（2026-10-22）
