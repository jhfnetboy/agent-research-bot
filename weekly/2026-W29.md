# AI 重大技术变化周报 2026-W29

覆盖：2026-07-13 至 2026-07-19（Asia/Bangkok UTC+7）

**本周主线**：开源权重迎来两个“巨无霸”：Thinking Machines 的 Inkling（975B）和 Kimi K3（2.8T）；Agent RL 环境栈和自动红队开始工程化。

## 重大变化

### 1. Kimi K3：2.8T 参数开源前沿模型

- **发生了什么**：07-17 Moonshot 发布 Kimi K3，2.8T 总参数，1M 上下文，原生图文输入，承诺 07-27 前放出权重。采用 Kimi Delta Attention（称百万 token 上下文解码最多快 6.3 倍）和 Attention Residuals（称训练效率提高约 25%）（据官方推文与 AINews 转述）。
- **为什么重要**：开源权重规模首次达到数万亿参数，并在长上下文效率上做架构创新，长时程 Agent 的上下文成本有望继续下降。
- **来源**：[Kimi K3 技术博客](https://www.kimi.com/blog/kimi-k3)（2026-07-17，页面无日期，按官方推文日）；[Simon Willison](https://simonwillison.net/2026/Jul/16/kimi-k3/)（2026-07-16，美国时间）；[AINews](https://latent.space/p/ainews-kimi-k3-28t-a50b-the-largest/)（2026-07-17，二手汇总）

### 2. Thinking Machines 发布首个开源基础模型 Inkling

- **发生了什么**：07-16 Thinking Machines 发布 Inkling，975B 总参数、41B 激活的 MoE，1M 上下文，在 45T token 的文本、图像、音频、视频上预训练，同时预览更小的 Inkling-Small（二手）。Hugging Face 同日发文欢迎。
- **为什么重要**：美国出现可作为基线的大规模开放权重模型，W45 的 Inkling 2 Small 即是这一家族的后续。
- **来源**：[Hugging Face: Welcome Inkling](https://huggingface.co/blog/thinkingmachines-inkling)（2026-07-15，按页面日期）；[Thinking Machines on X](https://x.com/thinkymachines/status/2077454609551921208)（2026-07-16）；[AINews](https://latent.space/p/ainews-thinkys-inkling-975b-a41b/)（2026-07-16，二手汇总）

### 3. OpenAI GPT-Red：自动红队带来 6 倍的抗注入提升

- **发生了什么**：07-15 OpenAI 发布 GPT-Red，一个用于大规模发现提示注入漏洞的内部自动红队模型。对抗 GPT-Red 训练后，GPT-5.6 Sol 在重放强攻击时失败数比四个月前最好的生产模型少 6 倍（据 OpenAI 推文与 AINews 转述）。
- **为什么重要**：提示注入是 Agent 接入工具和网页后的头号风险，用 AI 攻击 AI 再拿来训练防御，形成了安全方面的自我改进闭环。
- **来源**：[OpenAI: GPT-Red](https://openai.com/index/unlocking-self-improvement-gpt-red)（2026-07-15）；[AINews](https://latent.space/p/ainews-thinkys-inkling-975b-a41b/)（2026-07-16，二手汇总）

### 4. Prime Intellect verifiers v1：Agent RL 环境拆成任务集、harness、运行时

- **发生了什么**：07-13 Prime Intellect 发布 verifiers v1，重新设计 Agent RL 与评测的环境栈，把环境拆为 taskset、harness、runtime 三层，支持“自带 harness”的编码和 computer use 训练（二手）。
- **为什么重要**：环境标准化是开源 Agent RL 的基础设施，与 OpenEnv（W24）一起推动训练环境可复用。
- **来源**：[Prime Intellect on X](https://x.com/PrimeIntellect/status/2076447247693402301)（2026-07-13）；[AINews](https://latent.space/p/ainews-codex-usage-up-10x-in-6-months/)（2026-07-14，二手汇总）
