# AI 重大技术变化周报 2026-W22

覆盖：2026-05-25 至 2026-05-31（Asia/Bangkok UTC+7）

**本周主线**：Claude Opus 4.8 发布并预告“高于 Opus 的新一档模型”；行业注意力从模型本身转向 harness、记忆和多轮 RL 的工程细节。

## 重大变化

### 1. Claude Opus 4.8 与 Claude Code 动态工作流

- **发生了什么**：05-28 Anthropic 发布 Claude Opus 4.8，同日在 Claude Code 推出 dynamic workflows。据 AINews 转述，Opus 4.8 修复了社区对 4.7 的多项不满，在多数经济相关基准上领先，但独立评测总体结论是“有进步但不碾压”；Anthropic 还表示会在加强防护后推出“比 Opus 更聪明的新一类模型”，社区普遍解读为 Mythos 级模型将带着网络能力限制对外开放。
- **为什么重要**：按网络安全风险对能力分层开放开始成为产品线划分方式。竞争重点也从单轮回答质量转向长时程工作流执行。
- **来源**：[Anthropic: Claude Opus 4.8](https://www.anthropic.com/news/claude-opus-4-8)（2026-05-28）；[Claude Blog: dynamic workflows](https://claude.com/blog/introducing-dynamic-workflows-in-claude-code)（2026-05-28）；[AINews](https://latent.space/p/ainews-anthropic-raises-965b-series/)（2026-05-29，二手汇总）

### 2. 多轮工具 RL 的隐形 bug：Token-In, Token-Out

- **发生了什么**：05-29 Hugging Face 的 Clement Delangue 转发一篇深度分析：很多带工具调用的多轮 RL 训练循环在“解码输出、解析工具调用、再把对话重新分词”时会改变 token 序列，导致梯度落在模型从未采样过的序列上。建议的修法是严格的 Token-In, Token-Out，跨轮只维护一个 token 缓冲区，永不重新编码已采样 token。John Schulman 也强调 renderer 是消息和 token 之间的基础设施（二手）。
- **为什么重要**：Agent RL 的训练和推理不一致往往不报错，只会悄悄拉低效果。做多轮工具 RL 的团队都应检查自己的 rollout 管线。
- **来源**：[Clement Delangue on X](https://x.com/ClementDelangue/status/2060175330665508917)（2026-05-29）；[AINews](https://latent.space/p/ainews-founders-and-forward-deployed/)（2026-05-30，二手汇总）

### 3. 能力过剩：换个 harness，现有模型就能复现内部模型的数学结果

- **发生了什么**：有数学家报告 Claude Mythos 解出 Erdős 第 90 题，且证明路径与 OpenAI 此前的不同。Sébastien Bubeck 指出，配上合适的 harness，Mythos 和 GPT-5.5 都能复现内部模型一次性做出的结果。同周论文 Language Models Need Sleep 提出“睡眠”阶段，把近期上下文巩固进快权重后再清空 KV cache（二手）。
- **为什么重要**：很多能力被普通对话界面掩盖，harness 设计本身就是能力的一部分。长时程记忆仍是瓶颈，离线巩固成为一个研究方向，与 W45 Anthropic 谈 Agent 记忆的思路一致。
- **来源**：[Erdős #90 报告](https://x.com/__alpoge__/status/2059298565093196012)（2026-05-26）；[Language Models Need Sleep](https://x.com/iScienceLuvr/status/2059221770075562113)（2026-05-26）；[AINews](https://latent.space/p/ainews-new-ai-infra-decacorns-fireworks/)（2026-05-27，二手汇总）

### 4. LangChain Deep Agents v0.6：harness profile 与增量检查点

- **发生了什么**：05-27 LangChain 发布 Deep Agents v0.6，Delta Channels 把 200 轮编码会话的检查点存储从 5.3 GB 降到 129 MB；05-29 又把 harness profile 做成一等配置，让 Qwen、Kimi、DeepSeek 以低于前沿模型 20 倍以上的成本获得较好表现。同周还推出 Fleet 的 computer use 与版本化的 Context Hub（二手）。
- **为什么重要**：“模型、harness、记忆三者匹配”成为工程主题，为开源模型调专属 harness 是降低 Agent 成本最直接的手段。
- **来源**：[LangChain: Deep Agents v0.6](https://x.com/LangChain/status/2059634226836746483)（2026-05-27）；[LangChain: harness profiles](https://x.com/LangChain/status/2060349231722852680)（2026-05-29）；[AINews](https://latent.space/p/ainews-cognition-raises-1b-in-26b/)（2026-05-28，二手汇总）
