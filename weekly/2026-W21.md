# AI 重大技术变化周报 2026-W21

覆盖：2026-05-18 至 2026-05-24（Asia/Bangkok UTC+7）

**本周主线**：Google I/O 把 Gemini 3.5 定位为“能行动的模型”，MCP 走向无状态，METR 首份跨实验室风险报告聚焦内部 Agent 失控；“模型实验室都在做 Agent”成为共识。

## 重大变化

### 1. Google I/O 2026：Gemini 3.5 Flash 正式可用，Gemini Omni 亮相

- **发生了什么**：05-20 Google 发布 Gemini 3.5（官方标题为 frontier intelligence with action），Gemini 3.5 Flash 当天正式可用，3.5 Pro 预告下月推出，同时有 Gemini 3.5 Flash 的 computer use 能力。Gemini Omni 作为新家族把 Gemini 推理与生成式媒体合并，首个产品 Gemini Omni Flash 以视频生成和编辑为主。
- **为什么重要**：Google 把“行动能力”写进主线模型的定位，computer use 和 Agent 能力成为旗舰发布的核心卖点，而不是附加功能。
- **来源**：[Google: Gemini 3.5](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-5/)（2026-05-20）；[Google: I/O 2026 全部发布](https://blog.google/innovation-and-ai/technology/ai/google-io-2026-all-our-announcements/)（2026-05-20）；[AINews](https://latent.space/p/ainews-google-io-2026-gemini-35-flash/)（2026-05-20，二手汇总）

### 2. MCP 2026-07-28 规范候选版：协议改为无状态

- **发生了什么**：05-21 MCP 发布 2026-07-28 规范的候选版本。据 AINews 转述，核心变化是去掉握手和 session ID，任意请求可以打到任意服务实例；MCP Apps、Tasks 成为一等扩展，并加强鉴权、明确弃用策略。
- **为什么重要**：无状态让 MCP 服务可以像普通 HTTP 服务一样横向扩展和负载均衡，不再需要粘性会话，这是 MCP 从桌面插件走向生产基础设施的关键一步。
- **来源**：[MCP Blog: 2026-07-28 规范候选版](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/)（2026-05-21）；[AINews](https://latent.space/p/ainews-all-model-labs-are-now-agent/)（2026-05-23，二手汇总）

### 3. METR 首份 Frontier Risk Report：实验室会不会失控于自己的内部 Agent

- **发生了什么**：05-20 METR 发布 Frontier Risk Report（覆盖 2026 年 2 至 3 月），基于对 Anthropic、Google、Meta、OpenAI 的深度访问，包括模型思维链和未公开的能力、对齐与控制信息，核心问题是实验室是否可能失去对内部部署 Agent 的控制。METR 研究员还在 Anthropic 驻场一个月压力测试内部 Agent 监控系统（二手）。
- **为什么重要**：内部 Agent 监控从理念变成被外部机构检验的实践。这份报告也是后来 METR 量化 AI 研发加速（W45）的前身。
- **来源**：[METR: Frontier Risk Report](https://metr.org/blog/2026-05-19-frontier-risk-report/)（2026-05-20）；[METR on X](https://x.com/METR_Evals/status/2056800023149760666)（2026-05-20）；[AINews](https://latent.space/p/ainews-google-io-2026-gemini-35-flash/)（2026-05-20，二手汇总）

### 4. OpenAI 通用推理模型推翻离散几何中的单位距离猜想

- **发生了什么**：05-20 OpenAI 宣布内部模型在 Erdős 1946 年提出的平面单位距离问题上找到新的构造族，推翻了一个长期被认为成立的看法。OpenAI 强调这是通用模型而不是专门的数学系统，Timothy Gowers 等数学家给予了较高评价（二手）。
- **为什么重要**：长时程推理开始在真实研究问题上产生新结果，后续几个月 OpenAI 和 DeepMind 接连发布数学成果，这是起点之一。
- **来源**：[OpenAI](https://openai.com/index/model-disproves-discrete-geometry-conjecture)（2026-05-20）；[AINews](https://latent.space/p/ainews-openai-gpt-next-disproves/)（2026-05-21，二手汇总）

### 5. “所有模型实验室都在做 Agent”

- **发生了什么**：AINews 05-23 汇总：Greg Brockman 表态模型实验室越来越把 Agent 本身当产品，AI21 关闭模型团队转做 Agent，DeepSeek 首次组建 Harness 团队（二手）。同周 Cursor 发布 Composer 2.5，并透露正与 SpaceXAI 合作从头训练更大的模型。
- **为什么重要**：模型和 harness 联合训练成为趋势，也意味着最好的能力可能只在厂商自家 Agent 里才能完整发挥，开放 API 与自有 Agent 的竞合关系变得更紧张。
- **来源**：[AINews: All Model Labs are now Agent Labs](https://latent.space/p/ainews-all-model-labs-are-now-agent/)（2026-05-23，二手汇总）；[Cursor: Composer 2.5](https://x.com/cursor_ai/status/2056415413077233983)（2026-05-18）
