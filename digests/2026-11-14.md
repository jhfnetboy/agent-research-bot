覆盖时间：约 2026-11-13 至 2026-11-14 上午（Asia/Bangkok UTC+7）。官方文章日期按发布方页面标注；HN 分数为今早抓取时的数值。标注“据 AINews 汇总”或“二手”的内容未核对一手来源。

## 今日要点
1. Agent 商业接入一天之内落了三层：OpenAI 推出 ChatGPT Wallet（Agent 用一次性支付 token 付款，每笔生物识别确认）；Sierra 发布 Personal Agent Protocol 1.0，Shopify 全部商户默认启用；Brave Search API 支持 x402，Agent 按次用 USDC 付费、不需要 API key。与此同时 JPMorgan 被报道阻止 Agent 直接用客户卡号购物。
2. Google Research 公布 Antigravity /teamwork 多 Agent 系统的一批成果：证明 Courtade–Kumar 猜想并在 Lean 4 中形式化、自主形式化 Weil 猜想（约 180 万行 Lean）、两周把 Zircon 剩余 C++ 改写成约 80 万行安全 Rust；并开放给外部研究者。同日 Guardian 报道逻辑学家用 Claude 解读哥德尔笔记本，整理出 663 条定理。
3. 两篇 arXiv 论文给“Agent 自我改进”降温：只改 harness 笔记的收益比看起来小，而“harness 里放知识、权重里练稳定性”的组合更有效。
4. OpenAI 解散独立机器人团队，理由是通用模型（GPT-6 Astra）已能直接控制机器人。

## 重点话题

### 1. Agent 支付和商户接入：Wallet、Poppy、x402 同日落地

**发生了什么**
- OpenAI 于 2026-11-13 推出 ChatGPT Wallet，与 American Express、Mastercard、Visa 合作。流程：用户只添加一次卡；每次购买前查看商品、总价和所选卡，用 Face ID 或指纹确认；确认后由支付网络签发一个替代真实卡号的支付 token（含卡号、安全码、有效期），商家和 Agent 都拿不到真实卡信息，原有积分和争议保护保留。首批只对美国 18 岁以上 ChatGPT Pro 用户开放，通过 dots 使用。OpenAI 说之后会支持按额度、品类、时间段预授权，让 Agent 在限定范围内自主购买。同时发布 Commerce Partner Playbook，建议商户用 Web Bot Auth 识别签名请求、别让 CDN 和风控误拦 Agent，也可以做插件或在网站上加 WebMCP 工具。（[OpenAI, 2026-11-13](https://openai.com/index/introducing-chatgpt-wallet)）据 CNBC 报道 OpenAI 首发阶段不抽成（二手，转引自 [Agent News Daily, 2026-11-14](https://agentnewsdaily.com/brief/2026-11-14)）。
- Sierra（Bret Taylor、Clay Bavor）同日发布 Personal Agent Protocol 1.0（Poppy）。它定义个人 Agent 到达一家公司时如何表明身份、发现自己能做什么，主要复用 MCP、OpenAPI 和 UCP，授权走 OAuth。Shopify 让所有商户自动发布 Poppy 文件，并共同起草了商业扩展，把 Poppy 和负责下单结账的 UCP 连起来；Meta 的 Muse 访问每个网站时都会先找 Poppy；设计伙伴超过 100 家，Mercury、Synchrony、Turkish Airlines 已上线，Mercury 的转账请求仍要过账户审批策略。（[Sierra, 2026-11-13](https://sierra.ai/blog/releasing-poppy)）
- Brave Search API 于 2026-11-12 支持 x402：未付款的请求返回 HTTP 402 和价格，Agent 签一笔 Base 链上的 USDC 付款后重试，结果附带链上收据；LLM Context 和网页搜索均为每次 $0.005，限时代付 gas，不需要账户和 API key；推荐用 Stripe 开发的 CLI 钱包 Purl Wallet。（[Brave, 2026-11-12](https://brave.com/blog/search-api-agentic-payments/)）
- 反方向的信号：据 PYMNTS 转引 WSJ，JPMorgan Chase 阻止 AI Agent 用客户直接提供的信用卡号购物，而 Bank of America、Capital One、Citi 的卡在客户允许时已被 Agent 使用（二手）。HUMAN Security 的 10 月数据称 Meta Muse 占其观测到的 Agent 请求 59%，Meta 加 OpenAI 合计 89%，只有 1.9% 的请求到达结账或支付页（二手，未经审计）。（均转引自 [Agent News Daily, 2026-11-14](https://agentnewsdaily.com/brief/2026-11-14)）

**为什么重要**
- 这周前半段的主题是 Agent 准入之争（United 封禁第三方 Agent、OpenAI 收购旅行 Agent）。今天出现的是“准入的正规通道”：身份发现（Poppy、Web Bot Auth）、授权（OAuth、每笔生物识别）、付款（网络 token 或稳定币）各有一套方案。共同点是不再让 Agent 拿着用户的真实卡号或密码去点网页。
- 两条路线并存：卡组织路线（Wallet、Stripe Link 的一次性虚拟卡）面向消费者和现有风控体系；x402 路线面向机器对机器的按次计费，去掉了 API key 管理，对需要临时调用很多付费工具的 Agent 更顺手。
- 对开发者来说，Agent 能否被商户“认出来”开始变成工程问题：签名请求、Poppy 文件、WebMCP 工具都可能成为网站的标准配置。

**接下来关注**
- Wallet 的预授权（额度和品类）何时开放，以及 Anthropic、Google 是否跟进类似钱包；Poppy 和 UCP、MCP 的分工会不会被 AAIF 等标准组织吸收。
- 银行侧态度分化（JPMorgan 拦截 vs 其他行放行），以及“Agent 消费按借卡给家人处理”的争议规则是否成形。

### 2. Agent 做科研：Google /teamwork 的成果单和 Claude 读哥德尔笔记

**发生了什么**
- Google Research 于 2026-11-13 发文总结 Antigravity /teamwork 多 Agent 系统的成果。设计上两点：并行探索加专门的“证伪器”（Lean 4、原封不动的测试套件、模拟器、硬件计数器）自动判断候选解；按步骤切分上下文，每个 Agent 只拿到需要的文件和工具，协调者把任务交给全新的继任者，批评者和审计者在干净上下文里复核。工作流写成可自我改进的自然语言模式并自动路由。（[Google Research, 2026-11-13](https://research.google/blog/advancing-science-engineering-with-antigravitys-teamwork-feature/)）
- 文中列举的结果（均为 Google 自述）：与 CUHK 等合作证明 2013 年的 Courtade–Kumar 猜想并在 Lean 4 形式化（5000 万行）；/teamwork-LEAP 全自主形式化 Weil 猜想，约 180 万行 Lean、28,800 次子 Agent 调用；两周把 Zircon 微内核剩余 C++ 改写为约 80 万行安全 Rust，通过全部内核单测并在 arm64 上启动；libgav1 改写为 Rust 后比原 C++ 快 20% 到 30%；从零训练 9x9 围棋引擎，8 天内提升约 2600 Elo；Borg 调度上线两项改动，部分硬件上 TPU 抢占减少 24%。还提到一个长期运行的 /teamwork 分析过往轨迹后改进了 /boost，Google 称之为“一个 harness 优化另一个 harness”。外部开发者现在可以在 Antigravity 使用 /teamwork、/boost 和 Deep Review，另向 1 万名学术研究者提供 6 个月免费最高档额度。（同上）
- Guardian 于 2026-11-13 报道，赫尔辛基大学的 Jan von Plato 自 2017 年起以约每周一页的速度解读哥德尔 1940 年代 1,009 页速记笔记本；9 月起交给 Claude，几天内得到 650 页解读和 663 条定理目录。用 Coq 检查后约 400 条按原表述成立，约 200 条需要修正表述或补假设，约 50 条为假；Claude 还重建了哥德尔声称证明过但未发表的选择公理独立性证明，通过 Coq 检查。（[The Guardian, 2026-11-13](https://www.theguardian.com/science/2026/nov/13/kurt-godel-notebooks-ai-helps-unlock-hidden-discoveries-man-who-transformed-maths)；数字细节另见 [AI Weekly](https://aiweekly.co/alerts/von-plato-uses-claude-to-extract-663-theorems-from-gdel-notes)）
- RSI 相关的二手信号（据 AINews 汇总）：有团队把 Agent 循环用于一次完整预训练，得到 801-30B-A3B，作者称优于 Qwen3-30B-A3B；PostTrainBench 上 Fable 5.2 与 5.1 得分相同，作者归因于系统卡里写明的“在 AI 研究上刻意压低能力”。（[Latent Space AINews, 2026-11-13](https://latent.space/p/ainews-jensen-huang-resigns-after-33-years-leading-nvidia/)）

**为什么重要**
- /teamwork 的成果几乎都挂在可自动验证的目标上（Lean、测试套件、硬件计时）。这再次说明长时程 Agent 的上限取决于有没有可靠的证伪器，而不只是模型本身。“上下文按构造切分 + 干净上下文复核”是可以直接借鉴的 harness 设计。
- “harness 优化 harness”和 Agent 跑预训练都是递归自我改进的具体形态；同时前沿实验室在 AI 研发能力上主动封顶（Fable 5.2），两种力量在同一周出现。

**接下来关注**
- Google 承诺的形式化证明模式和 deep-dive 教程；Weil 猜想形式化等结果的论文和代码是否公开、能否被独立复核。
- 哥德尔笔记的重建证明需要逻辑学界审阅，Guardian 引用的教授尚未看过该证明。

### 3. Harness 自我改进的边界：知识放 harness，可靠性练进权重

**发生了什么**
- “Agent Self-Improvement with Frozen Weights”（2026-11-08）：固定权重的 9B 开放模型，由更大的教师模型根据失败轨迹写 harness 笔记。在生成的客服决策任务上，看过失败轨迹的笔记比同流程但不看失败的笔记高 4.0 个百分点，但“反复试、保留得分更高的笔记”这个搜索过程本身就占了约 60% 的总提升；放到完整客服对话里没有显示出改进。（[arXiv 2611.11342](https://arxiv.org/abs/2611.11342)）
- “Knowledge in the Harness, Reliability in the Weights”（2026-11-11）：Gemma 4 12B 客服 Agent 从按需加载的 skill 读政策；每轮由模型自己诊断失败对话、把规则写进 skill，规则要过代码检查、反例自审、配对重测和噪声校准的验证门；再用 GRPO 在完整多轮工具对话上训练 LoRA。全程不用更强的教师模型，实验在零售和航空领域。（[arXiv 2611.15268](https://arxiv.org/abs/2611.15268)）
- 配套的几篇：CAMG-II 研究用 on-policy 蒸馏把“记什么、何时读回”变成策略的一部分，主张用预训练里见过的普通文件操作而不是专用记忆工具（[arXiv 2611.14009](https://arxiv.org/abs/2611.14009)）；ToolTurns 基准含 2,620 题、1,827 个工具，最佳 Agent 单次请求成功率 69.6%，完整多轮对话只有 39.8%（[arXiv 2611.14925](https://arxiv.org/abs/2611.14925)）；“Breaking Bad”发现模型内部存在随失败累积而上升的“任务进展糟糕”方向，会先于 reward hacking 出现，适度减去它能减少 Qwen 的作弊，减太多则 Agent 会把失败测试看成通过（[arXiv 2611.14996](https://arxiv.org/abs/2611.14996)）。另据 AINews 汇总，TRUST 用统计门控把坏的 harness 更新从 45.59% 降到 2.78%。（[Latent Space AINews, 2026-11-13](https://latent.space/p/ainews-jensen-huang-resigns-after-33-years-leading-nvidia/)）

**为什么重要**
- 现在很多“自我改进 Agent”产品本质是改 prompt 和笔记。第一篇论文给出了需要的对照组：不做“同样搜索但不看失败”的基线，很容易高估学习效果。
- 几篇论文共同指向一个工程结论：规则和领域知识写进可审查的 skill，并加严格的验证门；行为一致性和多轮稳定性这类问题，靠 RL 或蒸馏进权重更有效。

**接下来关注**
- 托管 Agent 平台（Claude Managed Agents 的 evals、AgentRun 等）是否引入类似的验证门和对照基线；多轮对话成功率（ToolTurns 的 39.8%）会不会成为新的标配指标。

### 4. 通用模型接管机器人：OpenAI 解散独立机器人团队

**发生了什么**
- Fortune 于 2026-11-13 独家报道并经 OpenAI 确认：独立机器人团队解散，研究人员并入 Mark Chen 领导的主研究团队，应用机器人和硬件团队并入 Greg Brockman 的 Applied 组织。OpenAI 称这是为加速而非放弃机器人，理由是 GPT-6 Astra 等通用前沿模型已能直接用于机器人；文中引用的 Nvidia 研究里，Astra 驱动的 Agent 在一个仿真操作基准上成功率 74.8%，专用机器人模型最佳为 51.0%。人形机器人首次公开演示仍以 2027 年为目标。（[Fortune, 2026-11-13](https://fortune.com/2026/11/13/openai-disbands-robotics-team-as-its-general-models-start-running-robots/)）
- 同日 Anthropic 推出 Claude for Manufacturing 插件（连接 Autodesk Fusion、NetSuite、Microsoft 365、Infor，17 个 skill），并在研究预览一个“Model Hardware Standard”，用标准驱动连接机械臂、显微镜等设备。（[The Decoder, 2026-11-13](https://the-decoder.com/anthropics-claude-for-manufacturing-plugs-ai-directly-into-factory-software-to-automate-industrial-workflows/)）

**为什么重要**：具身智能正在被当作通用 Agent 的下游应用，和编码、法律、金融一样走“通用模型 + 领域 harness/驱动”的路线；专用机器人模型的空间转向端侧低延迟和现场数据。

**接下来关注**：Model Hardware Standard 会不会像 MCP 一样开放成协议。
