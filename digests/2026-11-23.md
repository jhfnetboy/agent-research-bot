## 重点话题

### 1. OpenAI 公开预训练 perplexity 曲线，提议跨实验室的“发展上限”

**发生了什么**
- Pachocki 在 OpenAI 官网发表《Perplexity and Intelligence》（2026-11-22）：主张预训练本质是训练一个压缩器（预测器），追踪 perplexity（等价于交叉熵损失）是理解 AI 进展的关键，并首次公开 OpenAI 自 GPT-3.5 起在内部主评测集上的 log-perplexity。（[OpenAI, 2026-11-22](https://openai.com/index/perplexity-and-intelligence/)）
- 公开的数字：GPT-3.5 约 0.99（流畅对话），GPT-4 约 0.91（能有效使用 CoT，催生推理模型）；降到 0.8 以下后出现网络安全和数学方面的“变革性能力”；模型到约 0.76 时开始在开放数学问题上产出突破性结果。他预计进入 0.68 到 0.7 区间会出现新的变革性能力，但不知道是什么，现有评测可能也测不到。评测集来自 OpenAI 内部代码库的固定快照（脚注 3）。
- RSI 相关表述：他认为“完全递归自我改进”（无人监督的全自动研发）显然应当避免，但更值得关注的阶跃来自 AI 参与一个具体环节，即预训练算法研究；最早 2027 年可能出现预训练基础进展的“雪崩”。脚注称 2026 年曲线的陡降主要来自长期研究和算力投入，自动化只占较小部分，但最新模型已有 AI 做出的实质设计贡献。
- 政策提议：各前沿实验室共同制定评测和红队安全论证的规范、透明度标准，并设定基于 perplexity 等指标的共同上限，在理解和监控 AI 行为达到具体里程碑（例如“CoT monitor 的继任者”）之前不越过。他也列出局限：各家数据集不同难以横比、与具体任务脱节、CoT 推理带来的能力提升不会降低 perplexity、不知道下限在哪。

**为什么重要**
- 这是前沿实验室首席科学家第一次把“暂停或限速”落到一个可量化、可跨实验室追踪的指标上，而不是只谈评测分数。对 RSI 话题来说，它给出了一个具体判断：比“AI 替代研究员”更早出现的风险点，是 AI 改进预训练算法本身。
- 对 Agent 开发者的直接含义：OpenAI 认为 Agent 能力的“底座”仍由预训练决定，后训练和 harness 是在“引出”潜在能力；同时他明确预期对齐审计效果下降、评测和训练意识（evaluation awareness）上升，这会影响以后如何信任 Agent 的评测结果。

**接下来关注**
- Anthropic、Google DeepMind 等是否回应或公开可比数字。HN 讨论（482 分、334 评论）的主要质疑是：数字只基于 OpenAI 内部代码库、与分词器相关、外部无法复现，以及需要独立审计来验证承诺；也有人认为这是 C-suite 第一次提出具体限速方案，是正面信号。（[HN, 2026-11-22](https://news.ycombinator.com/item?id=50601525)）
- 据 X 新闻摘要（二手，未逐一核实原帖），图中还标出一个未发布模型约 0.73，Sam Altman 转发称这是 OpenAI 近期最重要的文章之一；Musk 则回应称“pretraining”应直接叫“training”。（[X 新闻摘要, 2026-11-23](https://x.com/search?q=Pachocki%20perplexity)）

### 2. Agent 化攻击进入一线：Cairn 自主发现零日，Agent 框架本身也成了目标

**发生了什么**
- AWS 安全博客（CJ Moses，2026-11-20）：Amazon Threat Intelligence 9 月 10 日发现一台未设认证、公开暴露的 Cairn 实例。Cairn 是一个开源的自主渗透测试框架，给定起点和自然语言目标就能协调多个 Agent 找路径。操作者用简体中文写 prompt，9 月 8 日起约 48 小时针对中国大陆以外的东亚高校 IP，目标只是“obtain shell access”的各种变体。（[AWS Security Blog, 2026-11-20](https://aws.amazon.com/blogs/security/chinese-nexus-actors-cairn-ai-agents-found-a-zero-day-on-their-own/)）
- 结果参差：据 ToolSift 汇总的 AWS 原文细节，Agent 对一个开放的 Redis 尝试约 16 小时、148 步未成功，对 GPU 服务器做了 3 万多次登录组合也未成功；但对医学影像应用 MONAI Label，Agent 测绘 API 后发现上传端点的路径遍历漏洞，约 11 分钟从测绘走到写文件，随后写入 `sitecustomize.py` 拿到 root 反弹 shell。AWS 高置信度判断为零日，中等置信度归因中国关联。MONAI Label 11 月 22 日发布 0.8.6 修复。（[GitHub Advisory GHSA-qc22-rmgc-vg94](https://github.com/Project-MONAI/MONAILabel/security/advisories/GHSA-qc22-rmgc-vg94)；[MONAI Label 0.8.6, 2026-11-22](https://github.com/Project-MONAI/MONAILabel/releases/tag/0.8.6)；[ToolSift, 2026-11-23](https://toolsift.ai/agent-news/2026-11-23/)）
- Wiz（2026-11-17，18 日更新）：Microsoft 的 Python 包 `agent-framework` 1.26.1 和 1.26.2 在 11 月 17 日 20:35 和 21:08 UTC 被发布到 PyPI，21:30 前下架。恶意版本在 site-packages 根目录放 `.pth` 文件，只要 Python 启动就运行凭据窃取器，无需 import。攻击者疑似拿到了 Microsoft ESRP 发布流水线的客户端证书和私钥；工具在 `/tmp/cairn_pkg` 暂存并发送 `CAIRN_ESRP_PROBE2` 探测，自称 Cairn。Wiz 还捕获到攻击者本机的编码 Agent 配置，疑似开源 `Pi` harness。最后安全版本 1.26.0。（[Wiz, 2026-11-17](https://www.wiz.io/blog/malicious-version-of-microsofts-agent-framework-published-to-pypi)）
- Bell Canada 向 BleepingComputer 确认，11 月 17 日“an agentic threat actor”进入其系统，包括用于订购和开通专线的系统，从 Maximo 预生产副本窃取了企业客户联系人、工单标题和部分网络 IP，不含密码和附件；尚未确认攻击者身份。（[BleepingComputer, 2026-11-20](https://www.bleepingcomputer.com/news/security/bell-canada-says-agentic-hacker-stole-enterprise-customer-data/)）

**为什么重要**
- 11 月 16 日日报的 FBI ARTEX 警报和 18 日的 GTIG 报告点名过 CAIRN 等框架，这次是厂商用暴露的操作记录展示了完整链路：人只给目标清单和一句话目标，Agent 自主发现并利用零日。攻击方的“harness”和我们日常搭的 Agent 没有本质区别。
- Agent 框架本身成为供应链目标：agent-framework 周下载约 4.1 万，`.pth` 持久化意味着装过就中招。做 Agent 产品的团队需要把依赖锁版本、发布流水线凭据和 Agent 运行环境里的密钥暴露面当成一等问题。

**接下来关注**
- Microsoft 对 ESRP 证书泄露的根因说明。另：本日例行来源检查时，`microsoft/agent-framework` 的 GitHub 仓库和 releases.atom 对未登录访问返回 404（2026-11-23 检查），原因未见官方说明，我们已改为跟踪 PyPI 发布流。
- Cairn 项目方是否加认证默认值或使用限制；AWS 建议防守方转向自动化响应，人只核查结果。

### 3. 模型改写自己的权重，Agent 自主做后训练

**发生了什么**
- 《Language Models Can Rewrite Their Own Weights》（arXiv 2611.21885，作者主页标注 2026-11-17）：给一个开源 27B 模型（据检索摘要为 Qwen3.5 27B）提供自身权重、打过分的答案和运行自己的能力，它诊断失败原因并直接改写对应权重，不用梯度、不做训练。论文称其自改后在未见过的题上准确率提升 6.6 个百分点，连续 8 轮编辑准确率只升不降；还能把一个几乎失效的受损副本修复到原准确率的 80% 以上；该能力随规模出现，同族小模型要么不改、要么把自己改坏。（[arXiv 2611.21885](https://arxiv.org/abs/2611.21885)；[作者项目页](https://www.jiajunfan.com/projects/self-rewriting/)）
- 《AutoMaster》（arXiv 2611.26510，人大 RUC-AIBOX，见 2026-11-23 Hugging Face Daily Papers 榜单）：提出 Skill-FT，用自然语言 skills 在 teacher rollout 中压制坏习惯（无依据假设、无效重复、表面验证）、引出有效行为，再微调目标模型；AutoMaster 让一个 LLM Agent 自主完成轨迹分析、skill 设计、数据筛选和评测反馈。在 Terminal、Search、SWE 任务上，4B 和 9B 目标模型比普通 SFT 平均高 1.42 到 8.99 个百分点，代码已开源。（[arXiv 2611.26510](https://arxiv.org/abs/2611.26510)；[GitHub](https://github.com/RUCAIBox/AutoMaster)）

**为什么重要**
- 两篇都在 RSI 光谱上：一个把“推理时的改进”直接写进权重，模糊训练与推理的边界；一个把后训练流程本身交给 Agent。和 Pachocki 文章放在一起看，学界和实验室都在把“AI 改进 AI”拆成可度量的具体环节。

**接下来关注**
- Self-rewriting 的结果目前是单篇论文、单一模型族，需等独立复现；它的“只用前向传播”也意味着若可行，部署侧安全边界（谁能让模型改自己的权重）需要重新定义。

## 其他动态
- **Perplexity Monitor API**（补报）：11 月 16 日上线，用自然语言定义监控主题或页面，按计划检查，有相关更新时发签名 webhook，页面监控返回文本 diff。据 ToolSift 转引 The Decoder（二手），定价每千次请求 1 美元，Perplexity 自测在 60 个主题上 8 小时找到 63 个新页面，对比 Firecrawl 20 个、Exa 15 个。（[Perplexity, 2026-11-16](https://www.perplexity.ai/hub/blog/introducing-perplexitys-monitor-api)；[ToolSift, 2026-11-23](https://toolsift.ai/agent-news/2026-11-23/)）
- **Masullo GRH 草稿的 Lean 众包形式化**：一份 claude.ai artifact 展示 Lean 4 形式化进度，参与的数学家在 HN 欢迎大家“把有余量的 token 指向这个项目”，并提醒勘误中的数百个问题轻重不一，现在判断核心是否有漏洞为时过早。（[GitHub mccorvie/riemann-masullo](https://github.com/mccorvie/riemann-masullo)；[HN, 2026-11-22](https://news.ycombinator.com/item?id=50605045)）
- **Agent 舰队公开“攻打” P vs NP**：pequalnp.com 实时展示协调的 Agent 舰队，以已检查引理数作为两个方向的“权重”，并注明这不是概率也不是证明，另设被驳倒方案的“墓地”。（[pequalnp.com](https://pequalnp.com/)；[HN, 2026-11-22](https://news.ycombinator.com/item?id=50604314)）
- **AltRA-Test**：判断 LLM judge 能否替代一名人工标注者的统计检验，支持每题标注者不同的场景；实验中约 100 题常常就够，约一半任务设置里 LLM 通过。（[arXiv 2611.26073](https://arxiv.org/abs/2611.26073)）
